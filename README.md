# India Rainfall & Climate Prediction — Streamlit App

## 1. Folder structure

Place the Streamlit file and the artifacts generated by your notebook like this:

```text
rainfall_app/
├── app.py
├── spatial_regime_features.csv
├── prepped/
│   └── district_lookup.parquet
└── models/
    ├── feature_cols.pkl
    ├── class_to_idx.pkl
    ├── rain_class_to_idx.pkl
    ├── climate_feature_cols.pkl
    ├── climate_target_cols.pkl
    ├── stage1_rain_gate.json
    ├── stage1_calibrator.pkl
    ├── stage2_calibrated.pkl
    ├── precip_bin_stats.json
    ├── climate_temperature.json
    ├── climate_temperature_max.json
    ├── climate_temperature_min.json
    ├── climate_humidity.json
    ├── climate_wind_speed.json
    └── climate_surface_pressure.json
```

These files correspond to the model artifacts saved by the supplied notebook.

## 2. Install dependencies

```bash
pip install streamlit pandas numpy xgboost scikit-learn joblib pyarrow pydeck
```

## 3. Run

From the app folder:

```bash
streamlit run app.py
```

## 4. What the app does

1. Loads the district lookup generated in Phase 0.
2. Lets the user select a State/UT, District and date.
3. Automatically resolves latitude, longitude and elevation.
4. Finds the corresponding spatial regime features.
5. Builds the same date-derived features used by the inference code.
6. Runs the calibrated two-stage rainfall model.
7. Runs the six climate regression models.
8. Places a marker at the selected district on an India-focused map.
9. Shows rainfall probability, expected rainfall, severity probabilities and climate predictions.

## 5. Optional Streamlit secrets for deployment

If the data/model folders are outside the app directory, create:

```text
.streamlit/secrets.toml
```

with:

```toml
DATA_DIR = "/path/to/prepped"
MODEL_DIR = "/path/to/models"
REGIME_PATH = "/path/to/spatial_regime_features.csv"
```

The code also accepts these values through the environment-specific Streamlit secrets mechanism.

## Important model note

The supplied inference code explicitly assumes June–September as the monsoon period. The app keeps that same assumption so the deployed feature construction matches the notebook.

The supplied model is a climatology-style predictor. The date is converted into day-of-year/cyclical features, while spatial regime variables such as historical rainfall statistics and coastal distance are used as model features. It should therefore be presented as a model prediction rather than a guaranteed operational weather forecast.
